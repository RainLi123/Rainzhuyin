# 注音小達人

給國小一年級的注音練習遊戲：看圖從兩個注音裡選出正確的，有練習、測驗、聽寫三種模式，收集星星換獨角獸、扭扭蛋、拿徽章。

**開始玩：** https://rainli123.github.io/Rainzhuyin/

- 不需要帳號，資料存在各自裝置的瀏覽器裡。
- iPhone 用 Safari 打開 →「分享」→「加入主畫面」；Android 用 Chrome 打開 → 選單 →「安裝應用程式」。
- 打開過一次之後，沒有網路也能玩。
- 家長區（要先算一題乘法）可以加字、匯出備份、把字庫分享給別人。

## 更新網站

換掉 `index.html` 後，把 `sw.js` 第 2 行的版本號加一（例如 `zhuyin-v3` → `zhuyin-v4`），大家下次連網打開就會拿到新版。
